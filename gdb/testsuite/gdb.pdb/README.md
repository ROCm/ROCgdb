# Basic PDB Tests

This branch retains eight PDB tests and their build-time fixtures.

| Test | Coverage | Fixture |
|---|---|---|
| `pdb-yaml-types.exp` | Basic CodeView types | `pdb-yaml-types.in.yaml` |
| `pdb-yaml-symbols.exp` | Module symbols and locations | `pdb-yaml-symbols.in.yaml` |
| `pdb-yaml-lines.exp` | C13 source lines | `pdb-yaml-lines.in.yaml` |
| `pdb-yaml-inline.exp` | Inline records and line ranges | `pdb-yaml-inline.in.yaml` |
| `pdb-yaml-lazy.exp` | Module-scan index fallback | `pdb-yaml-symbols.in.yaml` |
| `pdb-simple-info.exp` | Symbol queries and native execution | `pdb-test.cpp` |
| `pdb-compound-types.exp` | Static members and large field lists | `pdb-compound-test.cpp` |
| `pdb-lazy.exp` | Lazy versus readnow module expansion | `pdb-udt-collide-{main,a,b}.cpp` |

Compiled fixtures are built by `pdb_prepare_for_testing` using the selected
board. The `hip-sdk-pdb` board selects clang-cl and LLD from `HIP_SDK`.
The execution tests require a native Windows target.

YAML fixtures are generated by `pdb_prepare_yaml` using llvm-pdbutil,
llvm-readobj and Python 3. The helper compiles `pdb-yaml-stub.c`, matches
the generated PDB to that PE's GUID/age, and patches section contributions
with `pdb-yaml-setsc.py`. `pdb-yaml-addglobals.py` is retained for the
helper's optional globals path. Generated files stay in the test output
directory; synthetic YAML symbols do not describe the stub's instructions,
so these tests do not run it.

From an MSYS2 shell in the configured GDB testsuite build directory:

```sh
HIP_SDK=C:/AMD/ROCm/7.2 runtest --tool gdb \
  --target_board=hip-sdk-pdb GDB=../gdb.exe gdb.pdb/*.exp
```

This is a smoke-test subset, not the full PDB regression suite. The full
suite remains on `vuzelac/PDB/cooked_index`.
